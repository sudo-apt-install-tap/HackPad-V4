## **Overview**

A Macropad With **8** Keys addressable per key RGB and an OLED module

### Why?

My old macropad doesn't get used that often and I cant keep track of all the 16 keys. Thus this will be a more compact build for me and hopefully I will be able to integrate this fully into my system.

also because SCREEN WITH CLIKIES

### How?
Use the firmware in [FIRMWARE](firmware) . This is my first time using QMK and I'm proud of my work because this is much more efficient than circuitpy running KMK.
